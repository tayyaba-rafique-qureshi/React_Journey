# Paste App

A pastebin-style web app built with React, Redux Toolkit, and Tailwind CSS.
Create, edit, delete, and search through your saved text pastes, all stored locally in the browser via localStorage.
Supports copy-to-clipboard, shareable paste links, and a read-only view for each paste.
Built as part of my React learning journey following the Code Help by Babbar YouTube series.
