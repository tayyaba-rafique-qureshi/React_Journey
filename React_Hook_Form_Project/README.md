# React Hook Form

## What I learned

1. basic setup 
-> create input form basic like before 
-> connect form fields to react hook form using register and handle submission using handleSubmit


2. validation and error handling + styling

-> required, minLength, maxLength for basic validation
-> pattern validation using regex for strict input rules like letters only
-> conditional className to style error fields
-> error messages shown below inputs using errors object


3. Prevent Multiple same submissions 
-> used isSubmitting flag from formState to disable the submit button while the form is being processed. simulated an API call using a Promise with setTimeout to test it.
